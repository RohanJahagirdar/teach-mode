# Privacy Rules

1. The skill is portable and must remain free of proprietary project knowledge.
2. Current repository context may be used temporarily to perform the requested work.
3. Never persist company-specific, customer-specific, or proprietary information in `~/.teach/`.
4. Durable learning updates must be generic enough to stand on their own without the source company's context.
5. Learning updates require explicit learner approval before persistence.
6. Secrets and credentials must never be written to learning state.
7. Personal learning state must not be committed to the public repository.
